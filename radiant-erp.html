Radiant Agrovet ERP (v2) — Field Sales & Distribution Platform

A full-scale ERP for an agro-veterinary distribution company, covering field sales operations, inventory, invoicing, payments, payroll, expenses, and reporting. It replaces a legacy PHP application with a modern, secure, hierarchy-driven architecture, and includes a full ETL tool that migrated live production data and validated financial correctness through automated reconciliation.

Key Challenges & Solutions

Problems I ran into while building and migrating the system, and how I fixed them.

Migrating Live Financial Data

Thousands of invoices, payments, and customers had to move with zero tolerance for data corruption.

Solution: an idempotent ETL system with --pretend mode, and a reconciliation gate that blocks deployment if any financial mismatch is found.

Payroll Regression Bug

The legacy system wrongly recharged settled dues.

Solution: payroll logic rebuilt with historical row-based recalculation, covered by regression tests.

Permission + Row Scope

Simple RBAC was not enough for a hierarchical organization.

Solution: permission checks and row-level scope enforcement separated, backed by automated access-matrix tests.

Reporting Consistency

Reports did not match invoice-level data.

Solution: strict reconciliation between invoice breakdowns and aggregated report values, down to the smallest unit.

Silent Eager Loading Bugs

Partial ORM loading caused incorrect financial calculations.

Solution: a full-entity loading rule for every decision-critical financial operation, with regression coverage.
